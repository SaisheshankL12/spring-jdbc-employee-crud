# 🧩 Spring JDBC Employee CRUD Application

A simple **Spring Framework** based CRUD application using **JdbcTemplate**, **MySQL**, **Log4j2**, and **Lombok**.  
This project demonstrates how to perform Create, Read, Update, and Delete operations in a clean and modular way.

---

## 🚀 Features

- ✅ Spring JDBC (no Hibernate)
- ✅ Log4j2 Logging
- ✅ Transaction Management (`@Transactional`)
- ✅ Lombok for cleaner models
- ✅ MySQL Database Integration
- ✅ DAO Pattern implementation
- ✅ XML-based Spring Configuration

---

## 🧠 Tech Stack

| Layer | Technology |
|-------|-------------|
| Backend | Java 17, Spring Framework 7 |
| Database | MySQL 9.4 |
| Logging | Log4j2 |
| ORM / JDBC | Spring JdbcTemplate |
| Utility | Lombok |
| Build Tool | Maven |
